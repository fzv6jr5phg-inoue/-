# おこづかい手帖 ✧

ゆめかわデザインの、月のおこづかい管理アプリです。`index.html` 1枚で動きます。

## できること
- 月ごとに予算を複数つくる（名前・金額・色）／なおす／消す
- 支出の登録（金額・メモ・日付・予算・タグ）／なおす／消す
- 予算ごと・月全体の「のこり金額」と「のこり％」をリングとバーで表示
- タグで支出を絞り込み、タグ別の合計を表示
- 「これまで」タブで過去の月の記録を一覧
- 新しい月は前の月の予算をワンタップでコピー
- JSON でバックアップの書き出し・読み込み

## つかいかた
`index.html` をブラウザで開くだけです。データはそのブラウザの localStorage に保存されます。
スマホで使う場合は GitHub Pages などで公開して、ホーム画面に追加すると便利です。
